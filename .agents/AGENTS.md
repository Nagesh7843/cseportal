# Workflow Rules

When reviewing code and making edits, follow this systematic workflow:
1. **Check Frontend**: Analyze the frontend components and state management to understand the client-side impact.
2. **Check Backend**: Review the backend controllers, services, and APIs to ensure business logic is correct.
3. **Check DB Logic**: Verify the database entities, repositories, and schemas to ensure data integrity.
4. **Update Postman**: After any endpoint changes or additions, always check `postman_collection.json`. If the endpoint is not there, add it.
